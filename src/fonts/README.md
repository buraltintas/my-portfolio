# Fonts

Self-hosted so the build does not depend on Google Fonts responding.

- `ibm-plex-sans.woff2`: IBM Plex Sans, weights 400–700
- `source-code-pro.woff2`: Source Code Pro, weights 400–600

Both are the variable fonts from [google/fonts](https://github.com/google/fonts)
(`ofl/ibmplexsans`, `ofl/sourcecodepro`), limited to these weights (Plex at
normal width) and to Latin, Latin-1 and Latin Extended, which covers Turkish.
Made with fontTools `varLib.instancer` and `subset`. Licensed under the SIL Open
Font License 1.1; see the OFL files here.
