<h2>Overview</h2>
<p>Yalınlı Platform is a local civic platform where Yalınlı residents report issues, share suggestions and follow community updates. The source for both the web app and the Go API is public on GitHub; the API lives at <a href="https://github.com/buraltintas/yalinli-api">github.com/buraltintas/yalinli-api</a>.</p>

<h2>Problem</h2>
<p>Local problems, suggestions, events and community announcements needed one organized place.</p>

<h2>Solution</h2>
<p>The platform brings public submissions, anonymous reporting, multilingual content and petition flows together in one place. Residents can sign petitions, and reports can be exported.</p>
