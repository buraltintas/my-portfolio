<h2>Overview</h2>
<p>Math Game is a practice game for people who are just learning multiplication. It is made for desktop screens and does not adapt to mobile.</p>

<h2>Problem</h2>
<p>Multiplication practice is repetitive, and I wanted it to feel more like a game for new learners.</p>

<h2>Solution</h2>
<p>The game asks quick questions and shows right away whether each answer is correct.</p>

<h2>My Role</h2>
<ul>
  <li>Frontend development</li>
  <li>Game flow design</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>Quick question-and-answer flow</li>
  <li>Instant feedback on each answer</li>
  <li>Designed for desktop use</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React</li>
  <li>JavaScript</li>
  <li>CSS</li>
</ul>

<h2>Why It Matters</h2>
<p>It is a small attempt at turning a repetitive exercise into a game.</p>
