<h2>Overview</h2>
<p>Math Game is a project that turns multiplication practice into a faster, more fun learning format. It is a practice game for people who are just learning multiplication, designed for desktop screens rather than mobile.</p>

<h2>Problem</h2>
<p>Repetitive math practice needed to feel more motivating for new learners.</p>

<h2>Solution</h2>
<p>The game offers a simple learning experience built on a fast question-and-answer flow with instant feedback.</p>
