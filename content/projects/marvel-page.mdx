<h2>Overview</h2>
<p>Marvel Page is a small frontend project that presents Marvel characters in a clean, readable interface, letting you browse them with search and pagination.</p>

<h2>Problem</h2>
<p>The character data needed to be easy to explore through pagination and search.</p>

<h2>Solution</h2>
<p>The project brings Marvel API data together in a simple search and listing experience.</p>
