<h2>Overview</h2>
<p>Marvel Page is a small frontend project that lists characters from the Marvel API. You can search for a character or go through the list page by page.</p>

<h2>Problem</h2>
<p>The character list needed search and pagination to be easy to go through.</p>

<h2>Solution</h2>
<p>The page shows the Marvel API data as a simple list you can search.</p>
