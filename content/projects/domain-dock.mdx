<h2>Overview</h2>
<p>DomainDock is a Chrome extension that ties notes to the domain of the site you are on. Notes stay in the browser's local storage; the extension has no backend and makes no network requests.</p>

<h2>Problem</h2>
<p>It is hard to keep notes organized by the site they belong to inside the browser while keeping the data under your own control.</p>

<h2>Solution</h2>
<p>Clicking the extension icon on any site opens that domain's notes, which save automatically as you type. An options page lets you search, sort, edit and delete all your notes. You can export notes as Markdown or JSON, and importing JSON merges notes from another browser.</p>
