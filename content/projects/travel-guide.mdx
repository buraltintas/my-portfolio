<h2>Overview</h2>
<p>Travel Guide is a simple travel app. You pick a place on a map and see its details.</p>

<h2>Problem</h2>
<p>I wanted the map to come first: find a place, then read about it.</p>

<h2>Solution</h2>
<p>The map is built with Leaflet, and the details for each place come from an API.</p>

<h2>My Role</h2>
<ul>
  <li>Frontend development</li>
  <li>Content flow design</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>Picking a place on the map</li>
  <li>Details for the selected place</li>
  <li>Interactive map built with Leaflet</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React</li>
  <li>Leaflet</li>
  <li>API integration</li>
</ul>

<h2>Why It Matters</h2>
<p>It brings a map library and an external API together in one small app.</p>
