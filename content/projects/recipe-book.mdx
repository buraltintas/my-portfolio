<h2>Overview</h2>
<p>Recipe Book is an app for adding recipes and finding them again later.</p>

<h2>Problem</h2>
<p>I wanted one place to add, view and search recipes.</p>

<h2>Solution</h2>
<p>The app shows recipes in a book-like layout, with a search bar for finding one quickly.</p>

<h2>My Role</h2>
<ul>
  <li>Frontend development</li>
  <li>Content layout design</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>Adding recipes</li>
  <li>Viewing recipes in a book layout</li>
  <li>Searching recipes</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React</li>
  <li>JavaScript</li>
  <li>CSS</li>
</ul>

<h2>Why It Matters</h2>
<p>The book layout makes a list of recipes feel more like a cookbook.</p>
