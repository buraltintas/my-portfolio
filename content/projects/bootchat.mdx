<h2>Overview</h2>
<p>BootChat is a simple instant messaging app that lets users sign in with Google and exchange messages in real time.</p>

<h2>Problem</h2>
<p>I wanted to build a lightweight chat product to explore authenticated real-time messaging without adding unnecessary complexity.</p>

<h2>Solution</h2>
<p>BootChat uses Firebase authentication and a real-time database to keep messages synced across clients with a minimal sign-in flow.</p>

<h2>My Role</h2>
<ul>
  <li>Product idea and UI direction</li>
  <li>Frontend development with React</li>
  <li>Google authentication setup</li>
  <li>Realtime data integration</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>Google sign-in</li>
  <li>Real-time message sync</li>
  <li>Simple chat interface</li>
  <li>Fast onboarding</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React</li>
  <li>Firebase Authentication</li>
  <li>Firebase Realtime Database</li>
  <li>Vercel deployment</li>
</ul>

<h2>Why It Matters</h2>
<p>BootChat is a compact product study in authenticated real-time communication and a clean foundation for a messaging experience.</p>
