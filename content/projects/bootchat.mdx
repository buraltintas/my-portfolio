<h2>Overview</h2>
<p>BootChat is a simple instant messaging app. Users sign in with Google and exchange messages in real time across three channels.</p>

<h2>Problem</h2>
<p>I wanted to build a small chat product to try authenticated real-time messaging without extra complexity.</p>

<h2>Solution</h2>
<p>Sign-in uses Firebase Authentication with a Google popup. Each channel is a Cloud Firestore collection, and the app listens to it with <code>onSnapshot</code>, so new messages show up on every open client.</p>

<h2>My Role</h2>
<ul>
  <li>Product idea and UI direction</li>
  <li>Frontend development with React</li>
  <li>Google authentication setup</li>
  <li>Cloud Firestore integration</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>One-click Google sign-in</li>
  <li>Real-time message sync</li>
  <li>Three chat channels</li>
  <li>Simple chat interface</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React with Create React App</li>
  <li>Firebase Authentication</li>
  <li>Cloud Firestore with real-time listeners</li>
  <li>Vercel deployment</li>
</ul>

<h2>Why It Matters</h2>
<p>BootChat let me try authenticated real-time messaging in a product small enough to finish.</p>
