<h2>Overview</h2>
<p>Register Page is a focused UI project built around a clean registration flow and form experience for new users. It is designed for desktop screens.</p>

<h2>Problem</h2>
<p>The registration form needed to be quick to understand and simple to use.</p>

<h2>Solution</h2>
<p>The project presents the registration process with a clean visual hierarchy, with form control handled by Formik and validation handled by Yup.</p>

<h2>My Role</h2>
<ul>
  <li>Frontend development</li>
  <li>Form UI design</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>Registration form</li>
  <li>Clean UI structure</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React</li>
  <li>Formik for form control</li>
  <li>Yup for validation</li>
</ul>

<h2>Why It Matters</h2>
<p>Register Page is a small example of making form flows clearer and lower-friction.</p>
