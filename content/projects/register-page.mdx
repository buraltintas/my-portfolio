<h2>Overview</h2>
<p>Register Page is a sign-up form for new users, built with React. It is made for desktop screens.</p>

<h2>Problem</h2>
<p>A sign-up form should be quick to understand and easy to fill in.</p>

<h2>Solution</h2>
<p>Formik handles the form state and Yup validates the inputs. The layout keeps the fields in a clear visual order.</p>

<h2>My Role</h2>
<ul>
  <li>Frontend development</li>
  <li>Form UI design</li>
</ul>

<h2>Key Features</h2>
<ul>
  <li>Registration form</li>
  <li>Form validation</li>
</ul>

<h2>Technical Highlights</h2>
<ul>
  <li>React</li>
  <li>Formik for form control</li>
  <li>Yup for validation</li>
</ul>

<h2>Why It Matters</h2>
<p>Almost every product has a sign-up form; this project focuses on just that piece.</p>
